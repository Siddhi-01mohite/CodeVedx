Utility Usage Prediction Tool

Project Overview

The Utility Usage Prediction Tool is a Python-based Machine Learning application developed to predict future utility consumption using historical usage data. The project provides a menu-driven console interface for managing utility records, training a prediction model, and generating predictions.

Features

- Menu-driven console application
- Add and update utility usage records
- Store and manage data using CSV files
- Train a Machine Learning prediction model
- Predict future utility usage
- Exception handling and input validation
- Organized project structure

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- CSV File Handling
- Git & GitHub

1. Clone the repository

2. Install dependencies

3. Run the application
